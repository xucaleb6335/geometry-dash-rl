How this agent decides

  1. 1
    Game state

    Every 4 physics ticks (60 times a second) the bridge mod in Geometry Dash reports the player (height, speed, mode, gravity) and the nearest objects around it: blocks, spikes, portals. Left panel.

  2. 2
    Encoder

    The encoder turns that into a fixed list of numbers in [-1, 1], all measured from the player, so the same situation looks the same anywhere in the level.

  3. 3
    Neural network

    Two hidden layers of 128 neurons. Each neuron adds up its inputs times learned weights and squashes the sum with tanh into [-1, 1]: orange is positive, blue negative. The lines show the largest inputs times weights.

  4. 4
    Action

    Two outputs, Release and Jump. Their difference goes through a softmax to give p(jump); the agent holds the button when p(jump) is over 50%. A separate critic network of the same shape estimates the value V(s), the reward still to come; it only matters during training.

Reading the picture

  • Scene. Numbered outlines are the objects in the encoder's slots (obstacles first, then nearest). The faint columns ahead of the player are the terrain profile: floor height, spikes on it, room overhead. Dimmed objects are known from other frames but not in this frame's report. Portals the bridge does not report are marked where the mode changed.
  • Neurons. Each hidden layer is sorted by how its neurons vote: the top rows push toward Release and the bottom rows toward Jump while they are positive (orange), and the other way while negative (blue). Hover one for its inputs; click it to pin it and plot it on the timeline.
  • Inputs. Each cell is one number the network sees. The timing code turns the distance to an object's left edge into a bump that slides left as the object approaches: the precise timing signal a small network needs.
  • Knock-out test. The panel on the right reruns the network with one input group set to zero, as if that object or signal were absent, and shows how p(jump) moves. It is a what-if, not the training signal.
  • Honest caveat. These policies are PPO plus behaviour cloning of checkpoint-search routes; on the hard levels they reproduce a learned route rather than react to unseen levels.
